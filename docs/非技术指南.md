# P6AI 是什么？（给土木行业朋友的非技术说明）

> 一句话：**P6AI 是一个帮你把施工计划自动写进 Primavera P6 软件的工具。**
> 你不用懂编程，这篇文章用大白话讲清楚它是干什么的、怎么用、安不安全。

---

## 一、它解决什么问题

做工程的人都熟悉 Primavera P6（下称 P6）——土木行业排进度计划的标准软件。
用 P6 排计划时，最费时间的不是"想"，而是"录"：几千道工序，一条条敲进去，
谁先谁后、每道干几天、之间什么关系……手工建网既慢又容易出错。

P6AI 的思路很简单：**把"录入计划"这件事交给电脑和 AI，人只负责检查和拍板。**

## 二、它怎么工作（打个比方）

可以把建计划想象成按图纸搭积木：

1. **方案变成图纸**：AI 读你的施工方案或计划，整理成一份"标准图纸"。
   图纸是一份结构化数据（技术叫 JSON）——你完全不用管它的格式。
2. **检查图纸**：工具自动检查有没有问题，比如：
   - 有没有工序忘了写工期？
   - 有没有"循环"（A 等 B、B 又等 A，永远等不完）？
   - 有没有工序挂错了位置？
3. **按图纸搭积木**：检查通过后，自动在 P6 的数据库里把项目、WBS、
   工序、前后逻辑关系全部建好。
4. **你来做总工**：打开 P6，找到这个项目，按一下 **F9**（进度计算），
   关键路径、浮时、甘特图就全出来了。

## 三、你实际会怎么用

```
1. 把施工方案发给 AI（比如 Claude、Codex），让它生成计划
2. 让 AI 调用 P6AI 校验这份计划（哪里有问题，它会告诉你）
3. 确认无误后，让 AI 调用 P6AI 写入数据库
4. 打开 P6 → 找到新项目 → 按 F9 → 看结果
```

全程你只需要：提供方案、检查 AI 给出的计划、在 P6 里确认结果。

## 四、安不安全？（大家最关心的问题）

- **动手前先备份**：每次写入前，工具自动把数据库复制一份（带时间戳），
  出问题随时能还原。
- **要么全成、要么全不成**：写入是一个整体，中间任何一步出错就全部撤销，
  不会写一半留下个烂摊子。
- **P6 开着不让写**：如果 P6 正在运行，工具会拒绝写入并提醒你先关闭，
  防止两边"打架"。
- **先检查再动手**：写入前先检查数据库结构对不对，防止写错地方。

## 五、常见问题（FAQ）

**我在 P6 里找不到新建的项目？**
把 P6 完全关掉再重新打开，到"项目"窗口的 EPS 树（比如 NEWEPS）下面找。

**为什么提示"数据库被占用"？**
P6 还开着。先完全关闭 P6 再试一次。

**会把我原来的项目搞坏吗？**
不会。工具只"新增"项目，不动你原有数据；而且每次写入前都有备份。

**我完全不会编程，能用吗？**
能用。你不需要写代码——你需要的是会用 AI 工具（比如能接 P6AI 的聊天助手），
把方案交给它就行。

## 六、几个名词，一分钟看懂

| 名词 | 大白话解释 |
|---|---|
| P6 / Primavera P6 | 工程进度计划软件，土木行业排计划的标准工具 |
| 数据库 | P6 存放项目数据的"大仓库"，就在你电脑里（一个 .db 文件） |
| WBS | 项目的"目录树"，比如：土建 → 桩基 → 主体结构 |
| 工序 / 活动 | 计划里最小的工作项，比如"桩基施工及检测" |
| 逻辑关系 | 工序之间的先后，比如"打桩完成后才能做检测"（完成-开始） |
| 工期 | 一道工序要干多少天 |
| 关键路径 | 决定总工期的那条"最紧链条"，哪里延误就影响哪里 |
| F9 | P6 的"进度计算"快捷键，按下后自动算出关键路径、浮时 |
| JSON | AI 和工具之间传递计划用的标准格式，你看不懂也没关系 |
