# P6AI 是什么？（给土木行业朋友的非技术说明）

> 一句话：**P6AI 是一个帮你把施工计划自动写进 Primavera P6 软件的工具。**
> 你不用懂编程，这篇文章用大白话讲清楚它是干什么的、怎么用、安不安全。

---

## 一、它解决什么问题

做工程的人都熟悉 Primavera P6（下称 P6）——土木行业排进度计划的标准软件。
用 P6 排计划时，最费时间的不是"想"，而是"录"：几千道工序，一条条敲进去，
谁先谁后、每道干几天、之间什么关系……手工建网既慢又容易出错。

P6AI 的思路很简单：**把"录入计划"这件事交给电脑和 AI，人只负责检查和拍板。**

## 二、它怎么工作（打个比方）

可以把建计划想象成按图纸搭积木：

1. **方案变成图纸**：AI 读你的施工方案或计划，整理成一份"标准图纸"。
   图纸是一份结构化数据（技术叫 JSON）——你完全不用管它的格式。
2. **检查图纸**：工具自动检查有没有问题，比如：
   - 有没有工序忘了写工期？
   - 有没有"循环"（A 等 B、B 又等 A，永远等不完）？
   - 有没有工序挂错了位置？
3. **按图纸搭积木**：检查通过后，自动在 P6 的数据库里把项目、WBS、
   工序、前后逻辑关系全部建好。
4. **你来做总工**：打开 P6，找到这个项目，按一下 **F9**（进度计算），
   关键路径、浮时、甘特图就全出来了。

## 三、具体怎么用（详细版）

下面每一步都写清楚了。全程你不需要写代码，只需要：**提供方案、
检查 AI 给出的计划、在 P6 里确认结果**。

### 第 0 步：准备

- 把你的施工方案整理成文字（Word、记事本、或者直接把关键内容发出来都行）。
- **关闭 P6 软件**。这是整个过程里唯一需要动手的"技术动作"，
  因为写入时 P6 必须处于关闭状态。

### 第 1 步：把这个工具介绍给 AI 助手

把你正在用的 AI 助手（比如 Codex、Claude）打开，先把**这个仓库链接**发给它：

```
https://github.com/kcwuy/p6ai
```

然后可以这样说（直接复制，把"方案内容"换成你的）：

> 请先阅读这个项目：https://github.com/kcwuy/p6ai ，理解它的用途和用法。
> 我有一份施工方案，想请你帮我把它建成 Primavera P6 项目。
> 方案内容如下：
> （在这里粘贴你的方案）

如果 AI 已经配置好了 P6AI 工具（比如 Codex 已经接上），
那就更简单，直接说：

> 把下面这份方案建到我的 P6 里：
> （在这里粘贴你的方案）

### 第 2 步：AI 生成并校验计划

AI 会把你的方案整理成一份标准计划，并且**先自动检查**：

- 有没有工序忘了写工期？
- 有没有"循环"（A 等 B、B 又等 A）？
- 有没有工序挂错了位置？

然后它会给你看一份"计划预览"：项目叫什么、分几大块（WBS）、
有哪些工序、先后顺序是什么。

这一步你要做的：**像审图一样过一遍**。
名字对不对？工期合理吗？顺序对吗？有不对的地方，直接让 AI 改，
改到满意为止。

### 第 3 步：确认后写入

你点头之后，AI 会调用工具把计划写入 P6 的数据库
（写入前自动备份，中间出错自动回滚，不会留烂摊子）。

如果 AI 回复"数据库被占用"，说明 P6 没有完全关闭——去把 P6
彻底退掉（任务栏、托盘都没有 P6 图标），再让它重试。

### 第 4 步：打开 P6 看结果

1. 打开 P6 Professional；
2. 左侧导航栏点"**项目**"窗口；
3. 在左侧的 EPS 树里展开（比如 NEWEPS），找到你新建的项目
   （名字是你跟 AI 定的）；
4. 双击打开它；
5. 按键盘上的 **F9**（进度计算）；
6. 甘特图、关键路径、浮时就都出来了。

> 如果一开始没看到新项目，把 P6 完全关闭再重新打开一次，
> 项目列表需要重启才会刷新。

### AI 说"我没有这个工具"怎么办？

- 把仓库链接发给它，让它先读 README 和这份说明，它会告诉你
  怎么配置（或者找懂电脑的同事帮忙配一次，之后就能一直用）。
- 也可以退一步：让 AI 只负责把方案整理成"计划文件"，
  再把文件交给会用命令行的人，按 README 里的步骤执行。

两种方式，本质都是"AI 出计划、工具写数据库"，区别只是谁来按最后一下。

## 四、安不安全？（大家最关心的问题）

- **动手前先备份**：每次写入前，工具自动把数据库复制一份（带时间戳），
  出问题随时能还原。
- **要么全成、要么全不成**：写入是一个整体，中间任何一步出错就全部撤销，
  不会写一半留下个烂摊子。
- **P6 开着不让写**：如果 P6 正在运行，工具会拒绝写入并提醒你先关闭，
  防止两边"打架"。
- **先检查再动手**：写入前先检查数据库结构对不对，防止写错地方。

## 五、常见问题（FAQ）

**我在 P6 里找不到新建的项目？**
把 P6 完全关掉再重新打开，到"项目"窗口的 EPS 树（比如 NEWEPS）下面找。

**为什么提示"数据库被占用"？**
P6 还开着。先完全关闭 P6 再试一次。

**会把我原来的项目搞坏吗？**
不会。工具只"新增"项目，不动你原有数据；而且每次写入前都有备份。

**我完全不会编程，能用吗？**
能用。你不需要写代码——你需要的是会用 AI 工具（比如能接 P6AI 的聊天助手），
把方案交给它就行。

## 六、几个名词，一分钟看懂

| 名词 | 大白话解释 |
|---|---|
| P6 / Primavera P6 | 工程进度计划软件，土木行业排计划的标准工具 |
| 数据库 | P6 存放项目数据的"大仓库"，就在你电脑里（一个 .db 文件） |
| WBS | 项目的"目录树"，比如：土建 → 桩基 → 主体结构 |
| 工序 / 活动 | 计划里最小的工作项，比如"桩基施工及检测" |
| 逻辑关系 | 工序之间的先后，比如"打桩完成后才能做检测"（完成-开始） |
| 工期 | 一道工序要干多少天 |
| 关键路径 | 决定总工期的那条"最紧链条"，哪里延误就影响哪里 |
| F9 | P6 的"进度计算"快捷键，按下后自动算出关键路径、浮时 |
| JSON | AI 和工具之间传递计划用的标准格式，你看不懂也没关系 |
